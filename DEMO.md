# Hallmark — demo guide

## Start it

| System | Command (run inside this folder) |
|---|---|
| macOS / Linux | `bash run_demo.sh` |
| Windows | `run_demo.bat` |

The script creates a Python environment, installs the requirements, **analyses every demo file live**
(printing a results table), and then starts the app. Open **http://127.0.0.1:8000**. Press `Ctrl+C` to stop.

You need Python 3.10+ and Tesseract OCR:
macOS `brew install tesseract` · Ubuntu `sudo apt-get install -y tesseract-ocr` ·
Windows: https://github.com/UB-Mannheim/tesseract/wiki (default install path is detected automatically).

## Files to upload (folder `demo/`)

In the GitHub version of the project the `demo/` folder is not included: create files 1–8 with
`python scripts/make_demo_files.py --trust` (the Kaggle samples are only in the demo kit).

| # | File | What it shows | Live result (measured) |
|---|---|---|---|
| 1 | `1_signed_certificate.pdf` | valid signature from a trusted (demo) authority | 94.8% · Strong evidence of authenticity (Verified) |
| 2 | `2_altered_after_signing.pdf` | bytes changed after signing | 5.7% · Likely forged |
| 3 | `3_content_added_after_signing.pdf` | content appended after signing | 9.1% · Likely forged |
| 4 | `4_name_covered_and_retyped.pdf` | white box over the name, new name typed on top | 25.9% · Suspicious |
| 5 | `5_clean_scan.jpg` | ordinary unsigned scan | 59.9% · Inconclusive |
| 6 | `6_name_pasted_into_scan.jpg` | name patch pasted into a scan (heat-map in *Detailed analysis*) | 46.3% · Inconclusive |
| 7 | `7_future_dated_certificate.pdf` | issue date in 2031 | 35.4% · Suspicious |
| 8 | `8_not_a_certificate.pdf` | a sales memo | score withheld |
| K1 | `kaggle_samples/kaggle_genuine_gradecard.jpg` | **real** genuine page (Kaggle) | 55.0% · Inconclusive |
| K2 | `kaggle_samples/kaggle_forged_logo_seal_signature.jpg` | **real** forgery of that same page (Kaggle) | 55.0% · Inconclusive |

Files 1–8 are synthetic test documents generated by `scripts/make_demo_files.py`; K1–K2 are real dataset images.
All results are computed live; nothing is pre-recorded. Some other Kaggle images (for example page 3) are too
low-resolution for OCR and get *score withheld*. That is also a genuine result.

## Suggested 5-minute flow

1. **File 1:** "Only a trusted digital signature can verify a certificate."
2. **File 2:** "One changed byte, and the signature check catches it mathematically."
3. **File 4:** "No signature, but the original name is still hidden under the white box."
4. **File 5:** "An unsigned scan can't be verified, so Hallmark says *inconclusive* instead of guessing."
5. **File 6:** open *Detailed analysis* and show the heat-map.
6. **K1 then K2:** both 55%. Then open `docs/EVALUATION.md`: "On the dataset's own split the AI model scores
   100%, because every test document is also in training. Tested on documents it never saw, it calls every genuine
   page forged. So Hallmark refuses to use it and says why."
7. Click **Download Report** on any result.

## Rules

* Run everything live; if you show a backup recording, say it is a recording.
* The Kaggle images show a real student's details. Show them only in the room; don't publish them.
* Don't set `HALLMARK_ALLOW_UNVALIDATED_MODEL=1` during a demo.
* After the demo, delete `trust_anchors/demo_root_ca.pem`.
